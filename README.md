# Open Source AI Tools

A curated, verified list of AI tools for content creators, local AI setups, and creative workflows. Each entry links to the official repo or site — install directly from the source.

## 1. OpenMontage
Agentic video production system — turns Claude Code, Cursor, and similar coding agents into a video editing studio.
Repo: https://www.google.com/url?q=https://github.com/Open-Montage/OpenMontage&source=gmail&ust=1786942579457000&sa=E
Note: Many near-identical forks exist under different usernames with copy-pasted READMEs. Use the link above.

## 2. Ideogram
Best-in-class AI image generation with excellent text rendering.
Site: https://www.google.com/url?q=https://ideogram.ai&source=gmail&ust=1786942579457000&sa=E
Note: This is a closed-source commercial tool (free tier available) — no GitHub repo exists. Use it directly on the web.

## 3. Voicebox
Local voice cloning tool, positioned as an ElevenLabs alternative. 43k+ stars.
Repo: https://www.google.com/url?q=https://github.com/jamiepine/voicebox&source=gmail&ust=1786942579457000&sa=E
Note: Many forks exist with identical descriptions — this is the original by creator Jamie Pine.

## 4. NVIDIA Nemotron 3 Ultra
Open-weight large language model (550B parameters, 55B active).
Note: This is a model, not an installable app — there's no single "install" repo. Access it via:
- Ollama: `ollama pull nemotron-3-ultra`
- OpenRouter: https://www.google.com/url?q=https://openrouter.ai&source=gmail&ust=1786942579457000&sa=E
- Hugging Face: search "Nemotron 3 Ultra"
Full local run requires ~189GB disk space (quantized) — likely impractical on a Mac; OpenRouter's free tier is the realistic path.

## 5. OmniRoute
Free AI gateway aggregating 230+ model providers (claims ~1.6B free tokens/month).
Note: A security caution — an npm package version (3.8.5) was flagged by Socket.dev for obfuscated code in May 2026; the maintainer patched it in 3.8.6. Many differently-named forks exist. Recommend using only a repo with a large, active contributor base and recent commits, and reviewing code before running. One actively maintained fork: https://www.google.com/url?q=https://github.com/diegosouzapw/OmniRoute&source=gmail&ust=1786942579457000&sa=E

## 6. Meetily
Privacy-first, on-device AI meeting notes — a Granola/Fireflies alternative. Community Edition is free and open source (Rust/Tauri, local Whisper/Parakeet transcription + Ollama summaries).
Repo: https://www.google.com/url?q=https://github.com/Zackriya-Solutions/meetily&source=gmail&ust=1786942579457000&sa=E

## 7. Easy Diffusion
Long-standing one-click local Stable Diffusion installer — no technical setup required.
Site: https://www.google.com/url?q=https://easydiffusion.github.io&source=gmail&ust=1786942579457000&sa=E

## 8. OpenGenerative AI
MIT-licensed, 200+ model local creative studio covering image, video, and lip-sync generation (Flux, Kling, Sora, Veo).
Repo: https://www.google.com/url?q=https://github.com/Anil-matcha/Open-Generative-AI&source=gmail&ust=1786942579457000&sa=E
Note: Runs with no content filter by default — use responsibly.

## 9. Palmier Pro
Open-source (GPL-3.0) AI-native macOS video editor by Palmier Inc (YC S24).
Repo: https://www.google.com/url?q=https://github.com/palmier-io/palmier-pro&source=gmail&ust=1786942579457000&sa=E
Note: The editor and MCP server are open source; generative AI features are paid/closed. Windows version not yet available.

## 10. HyperFrames
HeyGen's official framework for turning HTML/CSS/JS into rendered MP4 video via AI coding agents. Apache 2.0 licensed.
Repo: https://www.google.com/url?q=https://github.com/heygen-com/hyperframes&source=gmail&ust=1786942579457000&sa=E
